Architecture & access decisions

Reuse tools across clients

The in-app Gemini assistant and external MCP clients use the same NestJS tools. This keeps the business logic shared as new assistant clients are connected.

Keep access specific

Tools read member- and sport-scoped data. Partner sign-in uses OAuth with dedicated read-only scopes for access to platform information.

Reliable AI document workflows

Provider fallback, reusable document processing, and recovery for abandoned work.

  • LangGraph
  • Multi-provider LLMs
  • Hybrid OCR
  • Google Document AI
The problem
Keep document-based AI workflows responsive while handling provider failures, repeated requests, and interrupted processing jobs.
My contribution
Led the multi-provider AI architecture and built hybrid OCR with content-addressed caching, request deduplication, and heartbeat recovery.
  1. 01 / InputDocument contentIdentify reusable results
  2. 02 / ProcessingShared workDeduplicate concurrent jobs
  3. 03 / RecoveryHeartbeat checksRecover abandoned jobs
Reliability & evaluation decisions

Fallback by task

Typed model registries and LangGraph route work across OpenAI, Anthropic, and Google, with fallback behavior chosen at the task level.

Reuse work and detect regressions

Content-addressed caching avoids repeated processing. Golden datasets, automated scoring, and regression gates help assess model changes and provider selection.
